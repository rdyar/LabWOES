Boxerator Settings

One piece folder box template creator. This isn't always perfect but it should get you close.











It is normal to need to adjust the dimensions a bit. The depth on the left and right is the depth of the box plus the material thickness - these flaps fold over the top and bottom flaps so they need to be deeper.

If when you close the left and right flaps there is a gap please note this has more to do with the corner cutouts then the overall width of the template/sheet. Increasing the width of the template/sheet will make the gap worse if you use the same corner cutouts!

Make sure you make the box larger than the print/item you are shipping.

We usually cut the sheet size first and then cut out the corners. Then you can do the creases for the inside based on the shape. The creases on the left and right usually need to be out a bit as they will fold over the top and bottom flaps (this is not shown in the design). A clear ruler used for sewing is very useful for marking the outer creases.
